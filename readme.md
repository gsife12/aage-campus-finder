# AAGE Campus Finder

AAGE Campus Finder is a web application developed as part of the COSC 412 Software Engineering course at Towson University.

## About the Project

Campus Finder aims to help Towson University students discover campus organizations, clubs, events, and activities in one centralized platform. The goal is to make it easier for students to get involved, connect with their campus community, and stay informed about upcoming opportunities.

## Planned Features

- Student registration and authentication
- Campus club and organization directory
- Event discovery and management
- Posts and announcements
- Search and filtering
- Notifications and updates
- Administrative and moderation tools

## Technology Stack

The project plans to use:

- **Frontend:** React
- **Backend:** Node.js and Express.js
- **Database:** To be finalized
- **Version Control:** Git and GitHub

## Project Structure

The repository will be organized into separate directories for the frontend, backend, and project documentation.

## Development Status

The project is currently in its initial development stage. Features and documentation will be updated as development progresses.
